## Descripcion
Juego basado al juego arcade de Space invader o Galaga, en la cual cuenta con mecánicas nuevas, entre una de ella es la posibilidad de mejorar la nave del jugador cuando sube de nivel, esto lo consigue a matar una cierta cantidad de enemigos, también tener un sistema top de ranking para competir con el puntaje obtenido en el juego.
